SI QUELQUE CHOSE ECHOUE:

1. Error: "ModuleNotFoundError: No module named..."
   → pip install pandas plotly pytest streamlit

2. Error: "No such file or directory"
   → Vérifiez que vous êtes dans le bon répertoire:
     cd C:\projets\HACKATHON\ IT\ 2026

3. Error: "Port 8501 already in use"
   → Fermez le terminal précédent ou utilisez:
     streamlit run app.py --server.port 8502

4. Les tests ne passent pas
   → Relisez le message d'erreur
   → Vérifiez que fraud_detection.py existe
   → Relancez: python test_everything.py
